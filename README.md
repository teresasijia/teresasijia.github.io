# Sijia Zhang — personal website

Static site, no build step. Served by GitHub Pages from the `main` branch.

```
index.html        about
research.html     papers
cv.html           CV, with the PDF embedded
demo.html         interactive elicitation demo
assets/           stylesheet, demo script, precomputed demo tables
```

The demo runs entirely in the browser: it reads three precomputed binary tables and
does no model arithmetic. Nothing a visitor does is stored or sent anywhere.

Demo data is regenerated by the build scripts kept outside this repository.
